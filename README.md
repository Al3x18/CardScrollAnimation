# SwiftUI CardScrollAnimation

A **SwiftUI** training project for exploring advanced scroll animations and behaviors by [Kavsoft](https://www.youtube.com/watch?v=ytRim2TSdyY).

## Overview

The app displays a home screen with:

- **Balance cards** that scroll horizontally, with scale and transition effects during vertical scrolling
- **Expense list** that updates when the active card changes
- **Custom scroll behavior** using `ScrollTargetBehavior` to snap scroll positions precisely

## Notes

This repository is intended for **practice and learning** SwiftUI only. All data (cards and expenses) is static mock data and does not represent a production app.
